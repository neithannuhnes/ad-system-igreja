# AD System

Sistema web para administração de caixa, movimentações, vendas, atividades e membros de grupos.

## Requisitos

- Python 3
- PostgreSQL

## Configuração local

1. Crie um ambiente virtual e instale as dependências listadas em `requirements.txt`.
2. Crie um banco PostgreSQL.
3. Copie `.env.example` para `.env` e informe os dados do seu banco e uma chave secreta.
4. Inicie a aplicação com `python app.py`.

As configurações locais são feitas no arquivo `.env`, criado a partir do modelo `.env.example`.
